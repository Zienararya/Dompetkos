## How to run
### Clone this project
with https
```sh
git clone https://github.com/Zienararya/Dompetkos.git
```
with ssh
```sh
git clone git@github.com:Zienararya/Dompetkos.git
```
### Install dependencies
```sh
flutter pub get
```
### Run this project
```sh
flutter run -d <devices-name>
```
